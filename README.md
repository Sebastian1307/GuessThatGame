#  GuessThatGame

**“¿Qué juego es ese? — Adivina el juego a partir de una imagen.”**  
Pon a prueba tus conocimientos gamer adivinando el título del videojuego solo con una imagen misteriosa.

---

##  Demo en vivo

 [**Jugar ahora**](https://guess-that-game.vercel.app)

---

##  Descripción

**GuessThatGame** es un pequeño juego web donde debes adivinar el nombre del videojuego mostrado en pantalla.  
Cada intento cuenta, así que piensa bien antes de responder 

Perfecto para pasar el rato, retar a tus amigos o descubrir cuánto sabes del mundo gamer.

---

##  Estructura del proyecto

```
GuessThatGame/
├── src/
│   ├── scripts/
│   ├── assets/
│   └── styles/
├── index.html
└── README.md
```

- **index.html** → punto de entrada del juego  
- **src/** → código fuente y lógica del juego  
- **assets/** → imágenes de los juegos  
- **styles/** → diseño visual

##  Cómo ejecutar el proyecto localmente

1. **Clona el repositorio**
   ```bash
   git clone https://github.com/Sebastian1307/GuessThatGame.git
   cd GuessThatGame
   ```

2. **(Opcional) Instala dependencias**
   ```bash
   npm install
   ```

3. **Ejecuta el proyecto**
   ```bash
   npm run dev
   ```
   o simplemente abre el archivo `index.html` en tu navegador.

4. **¡Empieza a jugar!**
   Intenta adivinar los juegos y mejora tu racha.

---

##  Cómo jugar

1. Se mostrará una **imagen parcial o borrosa** de un videojuego.  
2. Escribe el **nombre del juego** que crees que es.  
3. Si aciertas, ganas puntos   
4. Si fallas, pierdes una vida   
5. ¡Intenta llegar lo más lejos posible!
